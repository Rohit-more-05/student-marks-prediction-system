# Student Intelligence Platform 🧠

An advanced AI-driven academic diagnostic system designed to predict student performance and provide actionable intelligence.

[![🚀 Launch App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://rohit-student-marks.streamlit.app/)

## 🌟 Features

- **Intelligence Module**: High-fidelity dashboard for real-time academic risk assessment.
- **Advanced Visualizations**: Radar charts for skill balancing and grade trajectory plotting.
- **Analytics Suite**: Model consensus voting and what-if sensitivity optimization.
- **SaaS Aesthetics**: Premium dark/light mode interface with modular CSS.
- **Automation**: Integrated GitHub Action to keep the Streamlit service continuously active.

## 🛠️ Technology Stack

- **Frontend**: Streamlit (Python)
- **Analytics**: Plotly & Scikit-Learn
- **Models**: Random Forest, XGBoost, SVM, Decision Tree, Logistic Regression
- **DevOps**: GitHub Actions (Keep-Alive Workflow)

## 🚀 Getting Started

1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Launch the app: `streamlit run app.py`
